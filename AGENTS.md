# Taran Moon — Agent Instructions

This is a cinematic portfolio website.

The website is NOT a generic AI/SaaS landing page.

The primary visual identity is:
- lunar
- cinematic
- editorial
- technical
- minimal
- monochrome

## Rules

1. Do not replace supplied lunar assets with placeholders.
2. Do not introduce unnecessary 3D libraries.
3. Do not add random gradients.
4. Do not use generic SaaS layouts.
5. Do not add animations without purpose.
6. Do not sacrifice mobile performance for desktop effects.
7. Always verify major UI changes in the browser.
8. Do not modify the animation architecture without documenting the decision.

## Development rules

Before changing architecture:
- inspect existing implementation
- inspect relevant documentation
- check dependencies
- explain the proposed change

After significant implementation:
- run lint
- run build
- test in browser
- check console
- check responsive layouts
