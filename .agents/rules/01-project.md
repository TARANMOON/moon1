# Project Rules — Taran Moon

- NEVER replace supplied cinematic assets with generated placeholders unless explicitly instructed.
- NEVER invent new visual concepts merely to fill empty space.
- NEVER turn the site into a generic AI/SaaS landing page.
- NEVER add 3D libraries (Three.js/Fiber) unless the existing architecture genuinely requires them.
- NEVER optimize away the cinematic experience in the name of simplicity.
- DO preserve the supplied lunar visual identity.
- DO verify every major motion change in an actual browser.
- DO measure performance after animation/asset changes.
