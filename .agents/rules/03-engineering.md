# Engineering Rules

- Architecture: Next.js App Router + TypeScript + Tailwind CSS.
- Moon Rendering: Isolated HTML5 2D Canvas sequence engine driven by scroll position.
- Asset Handling: Progressive image preloading (Critical -> Priority -> Stream).
- Performance: DPR capped at 2, 60fps frame scrubbing, zero layout shifts.
- Code Quality: Strict TypeScript types, component decoupling, clean React 19 hook patterns.
