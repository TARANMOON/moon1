# Design System Rules

- Primary Visual Identity: lunar, cinematic, editorial, technical, minimal, monochrome.
- Color Palette: Deep space black (#050507), lunar slate (#12131a), white text (#ffffff), muted telemetry gray (#9aa0a6), subtle lunar blue accent (#8ab4f8).
- Typography: High-contrast editorial display headers paired with clean technical monospace telemetry labels.
- Layout: Asymmetrical editorial balance, fine 1px orbital borders, subtle film grain.
- Prohibitions: No bright rainbow SaaS gradients, no cartoonish icons, no colorful badges.
