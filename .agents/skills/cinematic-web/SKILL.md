# Cinematic Web Skill

## Core Directives
1. **Monochrome Mastery**: Build predominantly with `#050507`, `#0c0d12`, crisp white typography, and fine orbital rules.
2. **Editorial Typography**: Combine uppercase display headers with technical monospace telemetry data.
3. **Restraint**: Never introduce generic SaaS gradients, colorful buttons, or cartoonish graphics.
