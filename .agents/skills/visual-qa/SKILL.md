# Visual QA Skill

## Verification Routine
1. Launch dev server and open browser subagent.
2. Scrub through entire page at Desktop (1920x1080) and Mobile (375x812).
3. Inspect screenshot artifacts for text overlap, scaling issues, or visual glitches.
4. Verify 0 console errors and clean hydration.
